CHAPTER 01 · PROJECTION

投影与三视图

三视图不是三个孤立的图，而是同一形体在三个方向上的正投影。先建立“三等”关系，再谈读图与补线；所有复杂的组合体，最终都要回到这条基准线上。

正投影第一角画法三等规律图线规范
1.1

正投影：工程图样的共同语言

投影法是用光线把物体“压”到平面上的方法。工程图样主要采用平行正投影，因为投射方向垂直于投影面，能准确反映物体的形状与尺寸关系。

01 / TRUE SHAPE

真实性

当平面或直线平行于投影面时，投影反映实形或实长。与投影面平行的轮廓，可以直接量取尺寸。

02 / ACCUMULATION

积聚性

当平面或直线垂直于投影面时，平面的投影积聚成一条直线，直线的投影积聚成一个点。

03 / SIMILARITY

类似性

当平面或直线倾斜于投影面时，投影变小但不改变形状类型，称为类似形。倾斜角度越大，投影越短。

04 / PROJECTION TYPE

中心投影与平行投影

中心投影的投射线交于一点，常见于透视图；平行投影的投射线互相平行。机械制图采用平行正投影。

CORE RULE

工程图样主要采用第一角正投影。判断一条线或一个面在视图中的表现，先问：它相对于投影面是平行、垂直，还是倾斜？

1.2

第一角画法与三视图配置

我国机械图样采用第一角画法：物体位于观察者与投影面之间。主视图由前向后投射，俯视图由上向下投射，左视图由左向右投射。

视图投射方向投影面主要反映第一角位置
主视图由前向后正立投影面 V长、高；通常反映形状特征左上方
俯视图由上向下水平投影面 H长、宽（前后深度）主视图下方
左视图由左向右侧立投影面 W高、宽（前后深度）主视图右方
看进口图纸时注意：第三角画法的视图配置与第一角不同，常见的配置是俯视图在主视图上方、右视图在主视图右方。读图前先看标题栏或投影符号，不能只凭位置猜测。
  • 主视图优先：一般选择最能反映零件形状特征的方向作为主视图的投射方向。
  • 六个基本视图：主、俯、左、右、仰、后。实际图纸不必全部画出，按表达需要选择。
  • 向视图：不按基本视图位置配置时，要在视图上方标注“A向”等字样，并在原视图附近用箭头指明投射方向。
  • 局部与斜视图：局部视图只表达局部形状，用波浪线断开；斜视图用于表达倾斜结构，必要时旋转放正并注明“旋转”。
1.3

三等规律：三视图的坐标约束

同一形体的三个视图必须满足“长对正、高平齐、宽相等”。其中“宽相等”最容易被忽略，它约束的是俯视图与左视图之间的前后深度。

FRONT ↔ TOP长对正
FRONT ↔ LEFT高平齐
TOP ↔ LEFT宽相等
EASY TO MISS

宽相等不是“宽度相同”。俯视图中的上下方向，对应左视图中的左右方向，二者都表示物体的前后深度。补画左视图时，先把深度尺寸量到正确方向，再画轮廓。

1.4

图线、幅面与比例

图线不仅决定“画得好不好看”，更决定“读得对不对”。同一种线型在图样中承担固定语义，不能凭习惯混用。

线型线宽主要用途读图提示
粗实线d可见轮廓线、可见过渡线物体上真实可见的边界
细实线约 d/2尺寸线、尺寸界线、剖面线、引出线不表示形体轮廓
细虚线约 d/2不可见轮廓线、不可见过渡线被遮挡的结构，需要“脑内补形”
细点画线约 d/2轴线、对称中心线、分度圆常用于定位与对称判断
波浪线约 d/2断裂边界、局部剖视图分界表示“只画到这里”
细双点画线约 d/2假想轮廓、极限位置、相邻辅助零件不是当前零件的真实轮廓
  • 线宽比例：粗线与细线宽度通常按 2:1 配置；同一张图样中，同类图线宽度应保持一致。
  • 中心线：细点画线两端应超出轮廓线 2～5 mm，便于读图时识别轴线和对称中心。
  • 虚线相交：虚线与虚线、虚线与中心线相交时，应交于线段处，避免出现“悬空”的点。
  • 图纸幅面：A0 841×1189、A1 594×841、A2 420×594、A3 297×420、A4 210×297（mm）。优先选用 A0～A4 基本幅面。
  • 比例：常用缩小比例 1:2、1:5、1:10，放大比例 2:1、5:1。无论比例如何，图上标注的尺寸数字始终是物体的实际尺寸。
标题栏：通常位于图纸右下角，包含零件名称、图号、材料、比例、绘图与审核等信息。读零件图的第一眼，应先看标题栏。
1.5

从一张图开始：读图顺序与易错点

拿到图样，不要立刻盯住某个尺寸。先建立“这是什么、从哪个方向看”的框架，再逐步进入局部细节。

  1. 读标题栏：确认零件名称、材料、比例和图号，建立对零件用途的预期。
  2. 找主视图：判断投射方向，找出最能反映形状特征的视图。
  3. 对齐视图：用三等规律把各视图对应起来，先看大轮廓，再看内部结构。
  4. 想象形体：先整体后局部，先可见轮廓后虚线结构，必要时结合剖视图。
  5. 核对尺寸与技术要求：确认基准、定形/定位尺寸、粗糙度和公差是否完整。
COMMON PITFALLS / 常见错误
  • 把细实线当轮廓线：尺寸线、剖面线和引出线都不是物体的边界。
  • 忽略宽相等：补左视图时把俯视图的上下方向直接当成左右方向，导致前后关系颠倒。
  • 漏读虚线：虚线表示不可见结构，常是孔、槽或内部台阶的关键线索。
  • 把第三角配置当第一角：进口图纸要先确认投影制，不能只看视图位置。
  • 按比例量图：图样比例可能缩小或放大，尺寸必须以标注数字为准。

CHAPTER 02 · FORM READING

组合体读图

组合体并不可怕，它只是若干基本体按一定位置关系“拼接”或“切割”的结果。读图的关键，是把一个复杂外形还原成几个熟悉的形体，再用投影关系逐一验证。

形体分析线面分析表面连接补第三视图
2.1

形体分析法：先把复杂体拆小

形体分析法是组合体读图的主线：把组合体分解为若干基本体，逐个想象其形状，再分析它们的相对位置和组合方式。

STEP 01

分

沿主要轮廓、台阶、轴线或对称面，把组合体分成棱柱、圆柱、圆锥、球等基本体。

STEP 02

想

根据每个基本体的特征视图，想象它在空间中的形状和大小。先整体，后局部。

STEP 03

合

按“叠加、切割、综合”的关系重新组合，检查各基本体之间的位置和表面连接。

STEP 04

验

用三等规律逐项核对投影，确认没有多画、漏画或虚实颠倒的图线。

MNEMONIC

先分后合，先外后内；先大后小，先形后位。不要一开始就纠结一条虚线的归属，先回答“整体由哪几块组成”。

  • 叠加：两个或多个基本体以共面、相切、相交等方式组合。
  • 切割：从一个基本体上挖去若干部分，常见于凹槽、切口、通孔。
  • 综合：既有叠加又有切割，是考试中最常见的组合形式。
2.2

线面分析法：一个线框对应什么

当形体有切口、斜面、相贯线或复杂交线时，单靠“拆基本体”可能不够。此时要切换到线面分析：把视图中的线框与空间中的面、线对应起来。

视图中看到的元素通常表示读图提示
封闭线框一个面、曲面投影或孔口边界结合相邻视图判断是平面、曲面还是孔
相邻线框不同表面，或同一表面被遮挡的部分分界线通常是棱线、交线或转向轮廓线
直线棱线、交线、转向轮廓线或面的积聚直线也可能是一个侧面的投影
曲线相贯线、截交线、圆或曲面转向轮廓常见于圆柱、圆锥、球与平面的相交
类似形：倾斜于投影面的平面，投影仍保持边数相同、凸凹关系相似的形状，但尺寸会缩小。看到“形状像但尺寸不对”的线框，要考虑它是否是倾斜面。
2.3

表面连接：哪里该画线，哪里不该画

组合体读图最常错在“多画一条线”或“漏画一条线”。判断依据是两表面的连接关系，而不是主观感觉。

COPLANAR / 不画线

共面

两表面平齐、投影完全重合时，分界处不画线。共面通常意味着它们属于同一个可见表面。

TANGENT / 不画线

相切

圆柱面与平面、两曲面之间平滑过渡时，相切处不画线，转向轮廓线按需要画出。

INTERSECT / 画线

相交

两表面相交会产生交线或相贯线，必须画出。常见于圆柱与圆柱、圆柱与平面相交。

OFFSET / 画线

不平齐

两表面有明显高低或前后错位时，分界处画线，读图时要判断哪一面更靠前。

INTERSECTION

相贯线通常向大圆柱的轴线方向弯曲。读图时先找两条圆柱的轴线，再判断曲线弯向哪一侧；不要把它误认成圆弧或椭圆的一部分。

  • 共面不画线：如果两个面在同一平面上，分界处没有真实棱线。
  • 相切不画线：相切是平滑过渡，不应出现突变棱线；但转向轮廓线仍需按投影规律画出。
  • 相交必画线：交线是真实存在的边界，漏画会导致形体无法闭合。
  • 不平齐要画线：高低差或前后差形成真实台阶，线型按可见、不可见分别处理。
2.4

补第三视图：从两条投影到完整形体

“已知两视图，补画第三视图”是组合体读图的高频题型。它考的不是画图速度，而是你对形体与投影关系的完整推理。

ORDER 01先外形
ORDER 02后内部
ORDER 03先可见
ORDER 04后虚线
  1. 抓特征视图：找出最能反映形体特征的那个视图，先据此建立整体形状。
  2. 对投影：把已知两视图按“长对正、高平齐、宽相等”对齐，确定每个特征的深度和高度。
  3. 分块想象：按基本体或切割块逐一想象，标出哪些轮廓在第三视图中可见，哪些会被遮挡。
  4. 补外轮廓：先画可见外轮廓，再补内部孔槽的虚线；不要一开始就陷入细节。
  5. 检查：用三等规律、表面连接关系和虚实线规则逐条复核，尤其检查相切处是否多画了线。
补缺线时：先找“投影缺什么”，再判断“该线是可见还是不可见”。如果一条线在某个视图中存在，在另一个视图中却找不到对应投影，通常说明形体判断有误。
2.5

高频错误清单

下面这些错误几乎都来自同一个问题：没有把“视图中看到的线”与“空间中真实存在的面/线”对应起来。

COMMON PITFALLS / 常见错误
  • 共面处多画一条线：把两个平齐的表面误认为有台阶。
  • 相切处多画一条线：把平滑过渡误认为交线，导致轮廓突变。
  • 漏画相贯线：圆柱与圆柱相交时，交线是真实边界，不能省略。
  • 虚线画成粗实线：被遮挡的结构仍然是不可见轮廓，线型不能随意升级。
  • 把转向轮廓线当成棱线：曲面转向轮廓线不是实际棱边，但在投影中需要表达。
  • 补视图时深度方向颠倒：忘记俯视图的上下对应左视图的左右，导致前后关系反了。

CHAPTER 03 · SECTION VIEWS

剖视与断面

外形看得见，内部看不清，就用剖视。剖切是假想的，但表达必须严谨：剖切位置、投射方向、剖面线、可见与不可见轮廓，每一处都在传递结构信息。

全剖半剖局部剖断面图
3.1

剖视图是怎么形成的

用假想的剖切面把物体剖开，移去观察者与剖切面之间的部分，再把剩余部分向投影面投射，所得的视图就是剖视图。

01 / IMAGINARY

剖切是假想的

剖切只发生在画这一个视图时，不改变物体的真实形状，也不影响其他视图的表达。

02 / POSITION

剖切位置要合理

剖切面应尽量通过孔的轴线、槽的对称面或内部结构的中心，才能把内形完整剖到。

03 / PROJECTION

剖后仍按正投影

移去靠近观察者的一半后，剩余部分照常投影；剖切面与物体接触的部分画剖面线。

04 / LABEL

剖切符号

粗短画表示剖切位置，箭头表示投射方向，大写字母标注“A—A”，与剖视图标题对应。

CORE

剖视图解决的是“内部结构表达”。如果外形简单、内形复杂，或不对称零件内部有孔槽，优先考虑剖视；不要为了“看起来专业”而给所有零件都加剖视。

3.2

全剖、半剖、局部剖：怎么选

剖视方式不是随意的。选择依据主要有三点：零件是否对称、内形与外形哪个更复杂、需要表达的范围有多大。

类型适用条件关键画法
全剖视图内部结构复杂、外形简单或不对称整个视图剖开，内部轮廓全部可见
半剖视图基本对称的零件，内形与外形都需要表达一半视图、一半剖视；分界用细点画线，不画成粗实线
局部剖视图只需表达局部内部结构，或外形不宜全部剖开用波浪线分界；波浪线不应与轮廓线重合或穿过孔槽
旋转剖视图用两个相交剖切面剖开，交线垂直于某一基本投影面先旋转到同一平面再投影；标注“A—A”
阶梯剖视图内部结构不在同一平面，用多个平行剖切面剖切位置转折处要标注；不要漏画转折线
斜剖视图倾斜内部结构，用倾斜剖切面剖视图可旋转放正，注明旋转方向
复合剖视图多个相交或平行剖切面组合按各剖切面的投影关系依次表达
SELECT

先看对称性，再看内形复杂度。对称件想同时表达内外形，优先半剖；内部结构只在局部，优先局部剖；内形复杂且外形简单，优先全剖。

3.3

剖面线：不是装饰，是材料信息

剖切面与物体接触的部分要画剖面符号（剖面线）。它不是阴影，也不是为了好看，而是表示“这里是实体材料”。

  • 方向：金属材料通常画成与水平方向成 45° 的细实线，间隔均匀。
  • 同一零件：同一零件在各剖视图中的剖面线方向、间隔应保持一致。
  • 相邻零件：相邻零件的剖面线方向应相反，或方向相同但间隔不同，以区分零件。
  • 宽度：剖面线用细实线，不能画成粗实线；剖面线应与主要轮廓线成一定角度，避免平行混淆。
  • 不画区域：孔、槽等空腔部分不画剖面线；螺栓、螺母等标准件沿纵向剖切时通常不剖。
装配图中的剖面线：相邻零件的剖面线方向相反或间隔不同，是“区分不同零件”的重要线索。读装配图时，先看剖面线，再找零件序号。
3.4

断面图：只画被切到的那一块

断面图只画出剖切面与物体接触部分的形状，不画剖切面后面的结构。它和剖视图的区别，是“只画切口”还是“连后面的可见结构一起画”。

REMOVED SECTION

移出断面图

画在原视图外侧，轮廓线用粗实线；通常需要标注剖切位置和字母。适合表达键槽、孔、肋板等断面形状。

SUPERIMPOSED

重合断面图

直接画在视图内部，轮廓线用细实线；不遮挡原视图时可以不标注。适合结构简单、断面较小的场合。

DIFFERENCE

与剖视图的区别

剖视图包含剖切面后方可见结构；断面图只表达剖切面与物体的接触部分，不画后续轮廓。

SYMMETRY

对称断面

对称的移出断面可画在剖切位置延长线上；不对称断面通常需要标注投射方向或字母。

REMEMBER

剖视图看“里面有什么”，断面图看“切口长什么样”。题目问“只表达断面形状”时，不要再把后面的孔壁或台阶画进去。

3.5

剖视图高频错误

剖视图的评分点往往不在“画得像不像”，而在规定是否遵守：分界线、剖面线、标注和虚实关系。

COMMON PITFALLS / 常见错误
  • 半剖分界画成粗实线：应使用细点画线，表示对称中心而不是实体棱线。
  • 局部剖波浪线穿过孔槽：波浪线应画在实体材料上，不能穿过空腔，也不能与轮廓线重合。
  • 剖面线方向或间隔不一致：同一零件在各剖视图中必须保持一致。
  • 漏画剖切符号：剖切位置和投射方向需要时不可省略，字母要与剖视图标题对应。
  • 把标准件纵向剖开：螺栓、螺母、销等标准件沿纵向剖切时通常按不剖处理。
  • 断面图画成剖视图：把剖切面后方的结构也画出来，导致表达冗余。

CHAPTER 04 · DIMENSIONING

尺寸标注

图形负责“像”，尺寸负责“准”。尺寸标注必须做到正确、完整、清晰、合理：不多不少，基准明确，加工和检验都能直接使用。

尺寸四要素尺寸基准定形 / 定位 / 总体尺寸符号
4.1

尺寸的四要素

一个完整的尺寸由尺寸界线、尺寸线、箭头和尺寸数字组成。四者缺一不可，且都要使用细实线。

EXTENSION LINE

尺寸界线

从尺寸的起点或终点引出，表示尺寸范围的边界。一般与被注轮廓垂直，并与尺寸线垂直。

DIMENSION LINE

尺寸线

表示尺寸方向，必须与被注线段平行。同一方向的尺寸线应尽量整齐排列。

ARROW

箭头

箭尖指向尺寸界线，表示尺寸的起止。空间不足时，箭头可以外置或用斜线代替。

NUMBER

尺寸数字

表示实际大小，与绘图比例无关。水平尺寸字头朝上，竖直尺寸字头朝左。

4.2

基准与三类尺寸

标注尺寸的第一步不是量图，而是确定基准。基准决定尺寸从哪里量起，也决定加工和检验时如何建立坐标系。

DESIGN DATUM

设计基准

根据零件在部件中的功能、装配关系确定的基准。通常优先作为主要尺寸基准。

PROCESS DATUM

工艺基准

为加工、测量或装夹方便而选定的基准。设计基准与工艺基准应尽量重合。

FORM SIZE

定形尺寸

确定各基本体形状和大小的尺寸，如直径、半径、长度、宽度、高度、槽宽等。

LOCATION SIZE

定位尺寸

确定各基本体之间相对位置的尺寸，如孔中心距、轴线位置、槽的定位尺寸。

SHAPE定形
POSITION定位
OVERALL总体
  • 总体尺寸：零件的总长、总宽、总高。总体尺寸不一定与定形、定位尺寸同时标注，避免形成封闭尺寸链。
  • 主要基准：通常只有一个，决定零件最主要方向的尺寸。
  • 辅助基准：为标注局部结构而增加的基准，仍需与主要基准建立联系。
  • 尺寸完整但不冗余：每个结构只标一次，能由其他尺寸自然确定的尺寸不要重复标注。
KEY IDEA

先定基准，再标定形，最后标定位。如果一张图上的尺寸都能从两个明确基准量出，读图和加工就会非常顺；如果尺寸到处“飞”，通常说明基准没有选好。

4.3

常用尺寸符号

符号不是缩写，而是尺寸语义的一部分。漏写 φ 或 R，可能让加工人员把直径当成半径，直接把零件做废。

4.4

标注规则：正确、完整、清晰、合理

尺寸标注的四个评价词不是口号，它们分别对应：符合标准、没有遗漏、读图方便、便于加工测量。

  • 正确：符合国家标准，符号、线型、箭头、数字方向都正确。
  • 完整：定形、定位、总体尺寸齐全，能唯一确定零件形状。
  • 清晰：尺寸排列整齐，数字不被图线穿过，尽量标注在形状特征视图上。
  • 合理：符合加工工艺和测量要求，基准明确，避免封闭尺寸链和重复标注。
PLACE

标在可见处

优先标注在可见轮廓和形状特征视图上，避免在虚线上标注。虚线标注既不清晰，也不利于加工读图。

ONCE

同一尺寸只标一次

同一结构在多个视图中重复标注会造成矛盾。选择一个表达最清楚的视图标注即可。

NO CHAIN

避免封闭尺寸链

首尾相接、形成闭合回路的尺寸链会产生过约束。应留出一个“自然形成”的尺寸或改为总体尺寸。

NO INTERSECTION

不在交线上标

相贯线、截交线是加工自然形成的，不应作为设计尺寸的基准；应标注基本体的轴线、直径或位置。

NUMBER ORIENTATION

水平尺寸的数字字头朝上；竖直尺寸的数字字头朝左；倾斜尺寸的数字应保持朝上的趋势。尺寸数字不能被任何图线穿过，不可避免时应断开图线。

4.5

标注体检：最常见的失分点

尺寸标注的错误往往不是“少一个数”，而是“多一个数”或“标错位置”。下面每一条都值得在交卷前逐一扫一遍。

COMMON PITFALLS / 常见错误
  • 封闭尺寸链：总长、分段长度首尾相接，尺寸互相制约；应去掉一个多余尺寸。
  • 重复标注：同一尺寸在主视图和俯视图各标一次，读图时容易出现矛盾。
  • 在虚线上标注：被遮挡结构不应作为主要标注对象，应换到可见轮廓或剖视图上。
  • 尺寸线方向错误：尺寸线没有与被注线段平行，或尺寸界线没有垂直引出。
  • 漏写 φ / R：直径与半径混淆，直接影响加工尺寸。
  • 在相贯线上标注：交线是自然形成的，无法直接测量，应标注基本体尺寸和位置。
  • 数字被图线穿过：尺寸数字不清晰，违反“清晰”要求。

CHAPTER 05 · PRECISION

技术要求

尺寸告诉你要做多大，技术要求告诉你要做多准。表面粗糙度、尺寸公差与配合、几何公差，是零件图从“形状正确”走向“可制造、可检验”的关键一层。

表面粗糙度尺寸公差配合几何公差
5.1

表面粗糙度：微观不平度

表面粗糙度描述加工表面微观峰谷的不平程度。它和尺寸精度不是一回事：尺寸可以很准，但表面仍然可能很粗糙。

Ra

轮廓算术平均偏差

最常用的表面粗糙度参数。数值越小，表面越光滑，但通常意味着更高的加工成本。

Rz

轮廓最大高度

在取样长度内，最大轮廓峰高与最大轮廓谷深的和。对表面峰谷高度更敏感。

UNIT

单位与常用值

Ra 单位通常为 μm。常见值有 0.8、1.6、3.2、6.3、12.5、25，数值越小越精细。

NOTE

统一要求

图纸右下角技术要求中可写“其余 Ra 3.2”，表示未单独标注的表面统一按该值验收。

Ra 参考值典型加工读图理解
0.8 / 1.6精磨、研磨、精细车削高精度配合面、密封面
3.2 / 6.3精车、精铣、磨削一般配合面、重要非配合面
12.5 / 25半精车、粗铣、铸造或锻造非配合面、一般外观面
5.2

加工不可能绝对精确，所以要给尺寸一个允许范围。公差就是上极限尺寸与下极限尺寸之间的差值，表示允许的波动量。

5.3

配合：孔与轴的三种关系

配合描述同一基本尺寸的孔与轴装配后的松紧关系。根据公差带相对位置，分为间隙配合、过渡配合和过盈配合。

CLEARANCE

间隙配合

孔的公差带完全在轴的公差带之上，装配后总有间隙。示例：φ30H7/g6、φ30H7/h6。

TRANSITION

过渡配合

孔与轴公差带部分重叠，可能出现间隙，也可能出现过盈。示例：φ30H7/k6。

INTERFERENCE

过盈配合

孔的公差带完全在轴的公差带之下，装配后总有过盈。示例：φ30H7/p6。

BASE

基孔制 / 基轴制

H7/g6 中的 H7 为基准孔，属于基孔制；h6 为基准轴。配合代号先写孔，后写轴。

看公差带谁在上面。孔在上、轴在下 → 间隙；部分重叠 → 过渡；孔在下、轴在上 → 过盈。拿不准时，用配合速判器把公差带画出来。

FRAME

几何公差框格通常分为三格：第一格写特征符号，第二格写公差值（若公差带为圆柱形，数值前加 φ），第三格及以后写基准字母。形状公差通常没有基准格。

  • 基准：用方框字母 A、B、C 标注，基准符号要与被测要素建立明确联系。
  • 箭头：指引线箭头指向被测要素；当被测要素是轴线时，箭头可指向尺寸线。
  • 公差带：公差值是公差带的宽度或直径，不是“允许的偏差 ±值”。
  • 读法示例：“⊥ | 0.05 | A”表示该要素相对基准 A 的垂直度公差为 0.05 mm。
常见混淆：同轴度、对称度、位置度属于位置公差，通常需要基准；圆度、圆柱度属于形状公差，通常不需要基准。看到框格第三格是否有字母，就能快速判断。
5.5

技术要求怎么写、怎么读

技术要求通常写在标题栏上方或图纸空白处，用文字补充图纸上难以直接标注的内容。读图时，它和视图、尺寸同等重要。

  • 材料与热处理：如“45 钢，调质处理 220～250 HBW”。
  • 未注公差：如“未注尺寸公差按 GB/T 1804-m”。
  • 未注粗糙度：如“其余表面 Ra 3.2”。
  • 表面处理：如发黑、镀锌、喷涂、阳极氧化等。
  • 质量要求：如“铸件不得有砂眼、气孔”“去除毛刺、锐边倒钝”。
  • 装配要求：如配合间隙、预紧力、密封性、试验压力等。
COMMON PITFALLS / 常见错误
  • 把 Ra 当作尺寸公差：Ra 控制表面微观不平度，不控制尺寸大小。
  • 认为 Ra 越小越好：应满足功能即可，过度提高表面质量会显著增加成本。
  • 忽略“其余”要求：未单独标注的表面可能由统一技术要求控制。
  • 把过渡配合当成过盈：过渡配合可能出现间隙，也可能出现过盈，不能一概而论。
  • 形状公差加基准：圆度、平面度等通常不需要基准，框格中不应机械照抄。

标准件与常用件

螺纹、键、销、轴承、齿轮和弹簧，都有标准化的画法与标记。读图时不需要重新发明它们，只需要准确解码代号，并知道哪些结构会影响装配。

6.1

螺纹：从标记读出全部信息

螺纹标记是一串高度压缩的信息。以 M20×2 LH–6g 为例，它同时说明了牙型、公称直径、螺距、旋向和公差带。

梯形螺纹Tr40×7传动用，牙型角 30°，承载能力强
锯齿形螺纹B40×7单向传动，承受单向轴向力

EXTERNAL

外螺纹画法

大径用粗实线，小径用细实线；螺纹终止线用粗实线。小径通常在端部画入倒角内。

INTERNAL

内螺纹画法

小径用粗实线，大径用细实线；剖开时剖面线画到小径（粗实线）处。

ASSEMBLY

旋合画法

内外螺纹旋合部分按外螺纹画法表达，其余部分按各自画法；标准件纵向剖切通常不剖。

LENGTH

旋合长度

短、中、长旋合长度分别用 S、N、L 表示；中等旋合长度 N 通常省略不标。

6.2

键、销、轴承、齿轮与弹簧

6.3

工艺结构：小结构，大作用

倒角、退刀槽、中心孔、圆角这些结构尺寸不大，却直接影响加工可行性、装配安全和疲劳寿命。

CHAMFER

倒角

去除锐边，便于装配并避免划伤。常见标注 C2 或 2×45°；轴端、孔口通常都要倒角。

RELIEF

退刀槽 / 越程槽

给刀具留出退出空间，保证螺纹、磨削或车削加工到底。尺寸需按标准或工艺要求标注。

CENTER HOLE

中心孔

轴类零件加工时用于定位和支承。中心孔有标准型式，图纸上常用简化标记。

FILLET

圆角

降低应力集中，提高强度。圆角与倒角不同：圆角是圆弧过渡，倒角是斜面切除。

KEYWAY

键槽

键槽宽度、深度和位置要与键的标记对应；轴槽与轮毂槽的尺寸体系不同。

CLEARANCE

装配让位

轴肩、孔口、螺纹末端常需留出让位结构，避免两个零件在拐角处干涉。

READ THE DETAILS

标准件和工艺结构往往藏在局部放大图、简化画法和技术要求里。读图时不要只看主轮廓，局部细节才是装配失败的常见原因。

6.4

标准件高频错误

标准件的错误通常很“整齐”：粗细线画反、左右旋看反、内径代号算错。交卷前用下面清单快速核对。

COMMON PITFALLS / 常见错误
  • 内外螺纹粗细线画反：外螺纹大径粗、小径细；内螺纹小径粗、大径细。
  • 把 LH 看成细牙：LH 表示左旋，细牙通过标注螺距表示。
  • 管螺纹按外径读：G1/2 等标记中的尺寸是管道公称尺寸，不等于螺纹大径。
  • 轴承内径代号算错：6208 的内径是 40 mm，不是 8 mm 或 62 mm。
  • 齿轮齿顶圆公式记错：标准直齿圆柱齿轮 da = m(z+2)，不是 mz。
  • 标准件纵向剖开：螺栓、螺母、销等沿纵向剖切时通常不剖。

CHAPTER 07 · PARTS & ASSEMBLY

零件图与装配图

零件图回答“这个零件怎么做”，装配图回答“这些零件怎么装成机器”。从零件到部件，读图的对象变了，但投影、标注与技术要求的基本功没有变。

零件图四项装配图序号 / 明细栏拆画零件
7.1

零件图：制造成零件的完整指令

一张完整的零件图必须包含四项内容：一组视图、完整的尺寸、技术要求、标题栏。少任何一项，都不能独立指导生产。

VIEWS

一组视图

用基本视图、剖视图、断面图、局部放大图等，完整、清晰地表达零件的内外形状。

DIMENSIONS

完整的尺寸

定形、定位、总体尺寸齐全，基准明确，符合加工和测量要求。

REQUIREMENTS

技术要求

表面粗糙度、尺寸公差、几何公差、材料与热处理、表面处理等。

TITLE BLOCK

标题栏

零件名称、图号、材料、比例、绘图与审核信息，是读图的入口。

  1. 看标题栏：确认零件名称、材料、比例和所属部件，建立功能预期。
  2. 分析视图：找出主视图，判断投射方向，用三等规律对齐各视图。
  3. 想象形状：结合剖视、断面和局部放大图，先整体后局部，先外形后内形。
  4. 读尺寸基准：找出主要基准和辅助基准，区分定形、定位、总体尺寸。
  5. 读技术要求：重点关注配合面、密封面、关键尺寸的粗糙度与公差。
  6. 核对加工可行性：思考这个零件如何装夹、如何加工、如何测量，检查是否有无法实现的结构。
PART DRAWING

零件图的“完整”不是“画满”，而是“没有歧义”。一个尺寸只要能唯一确定结构，就不应重复；一个结构只要能清晰表达，就不必堆叠视图。

7.2

装配图：表达零件之间的关系

装配图不要求把每个零件都画得像零件图那样完整，而是重点表达零件之间的装配关系、相对位置、连接方式和运动关系。

SPEC

规格 / 性能尺寸

表示部件规格、性能或工作能力的尺寸，如中心距、孔径、流量、承载能力。

ASSEMBLY

装配尺寸

表示零件之间装配关系的尺寸，包括配合尺寸和相对位置尺寸。

INSTALL

安装尺寸

部件安装在基础上或与其他部件连接所需的尺寸，如地脚孔距、安装孔直径。

OVERALL

总体尺寸

部件的总长、总宽、总高，用于包装、运输和空间布置。

7.3

序号与明细栏：装配图的索引系统

装配图零件多、线条密，必须依靠序号和明细栏建立索引。序号是视图中的“指针”，明细栏是整张图的“零件清单”。

  • 序号指引线：从零件的可见轮廓内引出，末端用圆点或箭头指向零件；不要与剖面线平行，也不要穿过多个零件。
  • 序号排列：序号应按顺时针或逆时针方向整齐排列，便于按顺序查找。
  • 序号字高：一般比图中尺寸数字大一号，保证醒目。
  • 明细栏：位于标题栏上方，自下而上填写；内容包括序号、代号、名称、数量、材料、备注。
  • 一一对应：视图中的序号必须与明细栏完全一致，不能出现“有号无栏”或“有栏无号”。
DETAIL TABLE

明细栏自下而上填写：最下面一行对应序号 1，向上依次增加。读图时从标题栏向上看，就能按序号顺序找到每个零件。

7.4

读装配图与拆画零件图

读装配图的目标不是“看懂所有线条”，而是弄清：有哪些零件、它们如何连接、如何运动、哪些尺寸决定装配。拆画零件图则是在此基础上还原单个零件。

STEP 01

看标题栏与明细栏

先知道部件名称、用途、零件数量和材料，建立整体功能框架。

STEP 02

分析视图

找出主视图和剖视方向，用剖面线、序号和轮廓区分各个零件。

STEP 03

理装配关系

判断轴、孔、轴承、端盖、密封件之间的配合、定位、连接和运动关系。

STEP 04

拆画零件

分离目标零件的轮廓，补全被遮挡的线条，再标注尺寸和技术要求。

  1. 分离零件：根据剖面线方向、间隔、序号和装配关系，把目标零件从装配图中“抽”出来。
  2. 补全轮廓：补画被其他零件遮挡的线条，恢复该零件的完整形状。
  3. 确定尺寸：从装配图的配合尺寸、安装尺寸和零件结构推算零件尺寸；不能直接从图上量取作为设计尺寸。
  4. 补充技术要求：根据装配关系确定配合、粗糙度、几何公差和材料热处理要求。
  5. 检查：把拆画出的零件图放回装配关系中进行核对，确认尺寸链和装配可行性。
COMMON PITFALLS / 常见错误
  • 把相邻零件的轮廓混在一起：不先看剖面线和序号，导致拆图时形状错误。
  • 漏补被遮挡轮廓：只看可见线，忽略装配后被其他零件盖住的结构。
  • 直接从装配图量尺寸：装配图可能按比例缩小，且许多尺寸由零件图决定。
  • 明细栏顺序读反：明细栏自下而上填写，最下面一行是序号 1。
  • 忽略装配尺寸：只关注零件形状，不读配合、安装和总体尺寸。

怎么读公差带

  • 零线表示基本尺寸，向上为正偏差，向下为负偏差。
